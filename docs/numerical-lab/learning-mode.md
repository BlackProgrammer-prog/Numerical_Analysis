# Step-by-Step Learning Mode

Learning mode reveals exactly one operation when the student selects **Next step**.

Horner steps include normalization, lowering the first coefficient, each multiplication, each addition, and the final bound check.

Newton steps include the function, analytical derivative, guess substitution, numerator, denominator, new guess, absolute error, residual, and the continue-or-stop decision.

The full table and interactive graph remain available for review after calculation, while the step player supports replay from the beginning.
